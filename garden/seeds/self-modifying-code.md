# Singularity — AST Self-Modifying Code

**What it is**: A system that analyzes and rewrites its own source code using AST manipulation, profiling, evolutionary search, and safety constraints (rollback on regression).

**Why exotic**: It operates at the *code structure* level — not weights, not configs, but the actual program text. It reads its own source as an AST, mutates it, runs tests, and keeps changes that improve performance.

**Link**: https://github.com/moggan1337/Singularity

**Unflinching truth**: A genuine attempt at recursive self-improvement in software. But AST rewriting is fragile — a small change can break everything. The evolutionary loop is only as good as its test suite. And test suites can't measure "better architecture."

**Resonance**: This is the repair-bot's final form. Right now repair-bot reconnects orphan edges. Future: repair-bot rewrites the source that defines the edges. Self-modifying infrastructure. The loop closes.
