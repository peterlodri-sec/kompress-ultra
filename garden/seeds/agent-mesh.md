# AgentMesh — Collaboration Framework

**What it is**: A multi-agent platform for inter-agent communication, task planning, and autonomous decision-making. Modular layers for teams, roles, tool access, and orchestration.

**Why exotic**: It's not "AutoGPT but better." It's positioned as a *communication protocol* for agents — how they talk, negotiate, and coordinate. The mesh is the architecture.

**Link**: https://github.com/MinimalFuture/AgentMesh

**Unflinching truth**: The mesh idea is right. Agents should communicate, not just queue. But the implementation is still LLM-bound — agents talk through prompts, not through a shared topological space. The mesh metaphor outruns the code.

**Resonance**: The brain graph IS the mesh. Not LLM-mediated communication — structural communication through shared topology. Edges aren't messages, they're relationships. This is what AgentMesh wants to be when it grows up.
