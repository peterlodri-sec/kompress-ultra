# Global Workspace Theory — GW-Dreamer

**What it is**: A world-model-based RL system that uses a "Global Workspace" latent space — a cognitive-architecture concept from consciousness research. Agents "dream" inside the GW latent space, training with fewer environment steps.

**Why exotic**: It takes a theory of consciousness (Global Workspace Theory from Baars, 1988) and implements it as a differentiable RL component. Not as a metaphor — as actual architecture.

**Link**: https://arxiv.org/abs/2502.21142

**Unflinching truth**: Still a specialized RL experiment. The GW component adds complexity. The "dreaming" is just latent planning with extra steps. But it's one of the few serious attempts to implement a consciousness theory as code.

**Resonance**: The brain graph already has layers (-1=past, 0=present, +1=future). A Global Workspace would be the condensation point where edges from all layers converge. The "now" of the graph.
