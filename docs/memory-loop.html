A compressed agent context pipeline that remembers across restarts using nothing but hash functions, dot products, and a JSONL file. No cloud. No GPU. No API keys. No paid services.

01 What it does

Write path

Every compression run prunes low-signal messages. Instead of dropping them forever, it:

  • Hashes message text into a 768-dim vector
  • Stores it in an in-memory Map
  • Persists to ~/.cache/ultrameshai/vector-store.jsonl
Read path

Next session, when a topic/goal is given:

  • Auto-loads the JSONL file into memory
  • Hash-embeds the query
  • Finds top-K by cosine similarity
  • Returns formatted memory string for system prompt injection

03 How it works — the math

hashEmbedding
The hashing trick
Each word → hash code → vector bucket. Frequency accumulated, then normalized to unit length.
// Each word's hash maps to a position in [0..768) for (word of text) { h = ((h << 5) - h + word.charCodeAt(i)) | 0; vec[|h| % 768] += 1 / wordCount; } // Unit-normalize → cosine = dot product return vec.map(v => v / magnitude);

No ML. No API. Deterministic. Runs on a toaster.

cosineSimilarity
What vector DBs do internally
Dot product of two unit vectors. 1 = same direction (similar), 0 = orthogonal (unrelated).
function cosineSimilarity(a, b) { for (i = 0; i < 768; i++) { dot += a[i] * b[i]; magA += a[i] * a[i]; magB += b[i] * b[i]; } return dot / (√magA × √magB); }

O(n·d) — linear scan at <10K entries is instant.

05 Before / After

Before (cloud)
  • PAID OVHCloud embedding API
  • HEAVY Local Milvus (HTTP, collections, indexing)
  • CONFIG API keys, endpoint URLs, collection names
  • FAIL Default fallback to 0.5 when Milvus down
  • COST OVHCloud quantum ~3000+ EUR
After (self-hosted)
  • FREE hashEmbedding (pure math, 0 ops)
  • LIGHT LocalStore (in-memory Map + JSONL file)
  • ZERO No config, no keys, no endpoints
  • ALWAYS Works offline, always returns signal
  • COST Disk space for a few KB of JSONL
